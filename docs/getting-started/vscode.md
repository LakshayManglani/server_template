# VS Code Setup

This project includes a pre-configured `.vscode/` folder to improve development.

## Install Recommended Extensions

To install all recommended extensions:

1. Open Command Palette (`Ctrl+Shift+P`)
2. Run: `Extensions: Show Recommended Extensions`

## Debug Configs

You can debug the project from the VS Code Run & Debug panel. Two launch configs are available:

- **Debug: Dev Server** → runs `pnpm dev`
- **Debug: Compiled Server** → runs `pnpm build` then `pnpm start`
